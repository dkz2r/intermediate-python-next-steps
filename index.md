This lesson is intended as a follow up to [Plotting and Programming in Python](https://swcarpentry.github.io/python-novice-gapminder/).

So what do you do after you finish an introduction to programming in Python? You've probably
already written a few scripts maybe even some larger programs. You might have been brought into
some established projects and been introduced to some more mature codebases. What might be apparent
is that there is so much more that can be done with Python!

In this lesson, we will explore some things that are a little beyond what we can cover in an
"introductory" lesson, but are not quite "advanced" either. This course will assume that you have
some experience with programming in Python, and that you are at least comfortable with the basics
of syntax and programming concepts.
